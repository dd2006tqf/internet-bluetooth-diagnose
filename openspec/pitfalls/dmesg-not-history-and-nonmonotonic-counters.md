# 用 `dmesg` / 单次采样判断「历史从未发生」，会把偶发故障误判成硬件损坏

> 发现于：2026-11-15
> 位置：板端排障（`dmesg` vs `journalctl -b`；`/proc/interrupts` 单次采样）
> 影响：把一次**可自愈的启动期解析异常**判成「CSI-2 数据从未到达 SoC、
> 需重插 FPC」，并据此写下 226 行错误排查记录，差点让人去拆机器。

## 现象

排查摄像头零帧，连续犯了三个错，每个单独看都不显眼：

**错一**：`sudo dmesg | grep -c "tdm0 rx0"` → **0**，
据此判断「TDM 一次都没被触发」。

**错二**：多次读 `/proc/interrupts`，`5908000.tdm` 那一行全是 0，
据此判断「自开机从未有过中断」。

**错三**：把上面两个「此刻为 0」合并成「从未发生过」，得出
「CSI-2 数据从未到达 SoC」——一个关于**全时段**的强断言。

真实情况（换 `journalctl -b 0` 查同一次 boot）：

```
$ sudo journalctl -b 0 | grep -c "tdm0 rx0"
149
```

**149 次 TDM 解析错误**，形态是 `width is 0, height is 1138`、
`hblank short! min is 11`。数据到了，TDM 在解析，只是解析失败并反复复位。
过一段时间自己收敛，随后稳定出帧（`received=268/271`、`corrupt=0`、`seq_gap=0`）。

## 成因

### `dmesg` 读的是环形缓冲区，不是历史

内核 log buffer 有固定大小（本板 `CONFIG_LOG_BUF_SHIFT` 决定的几百 KB），
开机跑几十分钟、中间有几万行日志之后，早期条目**被覆盖**。
此时 `dmesg` 只能看到最近一段，但它的输出**长得跟「什么都没发生」一模一样**——
都是一行 `0`。

`journalctl -b <N>` 读的是 systemd-journald 的**持久化**日志，
覆盖整个 boot，不受环形缓冲区覆盖影响。两者语义不同，不能互相替代。

### `/proc/interrupts` 的计数会被清零

`5908000.tdm` 这一行确实是「自开机累计」的——**除非驱动主动把它清零**。
sunxi-vin 的 TDM 复位路径里有：

```
__sunxi_tdm_reset_v2_handle:workqueue tdm_rx0 reset!!!, isp frame count is 0
```

复位会重置计数器。所以「此刻读到 0」有两种完全不同的成因：

| 读到 0 的含义 | 后续行为 |
| --- | --- |
| 从未有过中断 | 永远不会涨 |
| 刚被复位清零 | 下一帧到达就涨 |

单次采样无法区分这两者。只有**重复采样看趋势**才能。

### 根本上的推理错误：瞬时 ≠ 全时段

前两个是取证手段错，第三个是逻辑错。用一次采样去否定一段历史，
在没有「该量单调不减」保证的前提下是无效推理。
本案例里那个量恰恰**不**单调（会被复位），所以采样值 0 什么也证明不了。

## 修法

本次没有代码修法（采集实际是正常的）。方法论上的修法是：

| 要回答的问题 | 能用 | 不能用 |
| --- | --- | --- |
| 这个 boot 内发生过 X 吗 | `journalctl -b 0 \| grep -c X` | `dmesg \| grep -c X` |
| 计数器在涨吗 | 间隔重复采样，看差值 | 单次采样 |
| 硬件是不是坏了 | 先问「它上次工作时是什么状态」 | 从「现在不工作」直接推出硬件故障 |

第三条最值得记：**已知曾经工作过的系统突然不工作，优先怀疑状态，
而不是硬件。** 用户一句「我们之前不是完整跑过一次链路了吗」就点破了
整条错误推理——我漏掉了这次反证。

## 边界

- `journalctl -b` 也可能丢：`journald` 配置了 `Storage=volatile` 时同样只保留
  内存中的最近部分。本板是持久化的，所以能用。换成 volatile 就退回 `dmesg` 的困境。
- 「重复采样看趋势」要求采样间隔大于被观测对象的复位周期，否则每次都撞在 0 上。
  本案中 TDM 复位间隔只有几毫秒到几十毫秒，采样很容易全落空。

## 教训

**「现在没有」不等于「从来没有」；`dmesg` 不是历史，`/proc` 里的计数器也不是。**
在断言「从未发生」之前，先确认你读的那个量**能不能被清零**、你能读到的窗口**有多长**。
