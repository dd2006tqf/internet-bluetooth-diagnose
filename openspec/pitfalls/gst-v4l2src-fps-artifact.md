# gst 的 v4l2src 会把同一台设备的帧率量成三分之一

> 发现于：2026-11-11
> 位置：测量方法本身（`gst-launch-1.0 v4l2src` vs `v4l2-ctl --stream-mmap`）
> 影响：整批结论建立在错误的 fps 上（6.86 vs 18.56），差点判定「并行会话数字造假」

## 现象

同一天、同一台板、同一个 `/dev/video0`、同一分辨率，两条命令给出完全不同的帧率：

| 测量路径 | 实测 fps |
| --- | --- |
| `v4l2-ctl --stream-mmap` | 17.2 ~ 18.6 |
| 裸 ioctl 按产品序列 | 18.29 |
| 产品 `V4l2FrameSource` | 18.58 |
| **`gst-launch-1.0 v4l2src`（任意 `io-mode`）** | **6.5 ~ 6.9** |

gst 的数字**恰好是其他三条的三分之一左右**，这个比例太整齐，让人第一反应是
「另外三条测的是错的」或者「有并行会话在造假」。

## 成因

不是驱动问题，是 gst 的 `v4l2src` 在这条链路上不按预期工作。

排除过程（每一组都配了基线守卫）：

1. **`en-awisp` 有无** —— 两种都跑，同为 6.86 fps；
2. **四种 `io-mode`**（`mmap` / `userptr` / `dmabuf` / `dmabuf-import`）—— 同为 6.86；
3. **三档曝光** —— 同为 6.86；
4. **前后基线守卫** —— 每组实验前后各跑一次 `v4l2-ctl` 基线，
   三次分别为 **16.83 / 16.75 / 16.82 fps**。

第 4 条是决定性的：实验前后设备都以 16.8 fps 出帧，**说明设备全程健康，
测量差异不是设备漂移**。于是唯一剩下的变量就是 gst 自己。

gst 为什么慢三分之一，本轮没有查到根因（可能是 `videoconvert`/`jpegenc`
串联的反压、也可能是 `v4l2src` 的 buffer 分配策略）。但**根因未知不影响结论**——
结论是「这个工具在这台设备上不是可信的量尺」，这已经足够。

## 修法

**帧率一律以 `v4l2-ctl --stream-mmap` 或裸 ioctl 为准，不用 gst 测。**

gst 在本项目只保留一个用途：**预览画面**。它能把 NV12 转成 JPEG 给人眼看，
这个功能不受帧率失真影响。

可复用的预览命令：

```bash
ssh board 'gst-launch-1.0 -q v4l2src device=/dev/video0 num-buffers=5 \
  en-awisp=1 en-largemode=0 \
  ! "video/x-raw,format=NV12,width=1640,height=1232,framerate=30/1" \
  ! videoconvert ! jpegenc quality=92 \
  ! multifilesink location=/tmp/snap_%02d.jpg'
```

## 边界

- **这条不能推广成「gst 测帧率都不准」。** vivid 虚拟设备上 gst 是准的。
  它在这台板上失真，很可能与 sunxi-vin 的 buffer 模型或 1640x1232 的缩放路径有关。
- 判据不是「gst 的数字对不对」，而是**「同一设备上两个工具的数字是否一致」**。
  不一致时，不能靠「哪个更权威」来裁决，要靠第三条独立路径（裸 ioctl /
  产品代码）来打破平局。本次正是产品路径的 18.58 与 v4l2-ctl 的 18.6 站在一起，
  才把 gst 单独钉死。
- **三分之一这个比例可能是巧合。** 不要把它当成 gst 的固定偏差去「校正」——
  下次可能是别的比例，或者干脆不出帧。

## 教训

**两个工具给出不同答案时，先怀疑工具，别先怀疑对方。**

本次差点写成「并行会话声称的 18.33 fps 不成立」。真正救了结论的是
**基线守卫法**：每组变体实验前后都跑一次已知正确的基线，
基线动了 → 变体结论作废；基线没动 → 变体结论可信。

一个更省事的版本：**任何测量开始前，先用一个已知正确的量尺量一次同一件事。**
如果量尺之间彼此不一致，说明还没到能测量的阶段。

同类问题见 `oracle-exit-code-as-truth.md`（拿 oracle 的退出码当 ground truth）
与 `subdev-parm-to-devnode-parm.md`（拿 ioctl 返回值当生效证据）——
共同点是**判据本身没被验证**。
