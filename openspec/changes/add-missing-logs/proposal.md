# Proposal: add-missing-logs

## Why
项目中多个核心模块完全缺少日志或错误路径静默返回 false，导致：
- 安全相关的异常检测（traffic_anomaly_detector）零可观测性
- D-Bus 通信错误在 20+ 个错误路径中被吞没
- 蓝牙音频融合评估（Phase 2）完全不可追踪
- TCP 丢包监控、序列化、数据模型层的失败静默发生
- 客户端 C API 函数无任何日志记录

## What
系统性扫描并补全 server/ 和 client/ 中缺失的日志，按优先级分批实施：
1. 零日志文件（最高优先级）
2. 高缺口文件（D-Bus 错误路径、连接丢失等）
3. 中缺口文件（不一致日志、缺少入口/出口日志）
4. 客户端 C API 日志
