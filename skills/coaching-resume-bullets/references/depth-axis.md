# 追问轴：技术分点的深挖路径

面试官的技术深挖不是随机的。绝大多数追问落在三条轴上，每条轴按固定顺序升级。

**这条规律的价值**：不需要穷举问题，只需沿轴预置三层答案。面试官问够了自己会停；你要保证任何一层被停住时，那层都有干净的一句话。

---

## 三条轴

| 轴 | 探测什么 | 典型第一问 | 典型第三问 |
| :--- | :--- | :--- | :--- |
| **A 机制轴** | 你是真懂原理，还是只会用 | 它内部是怎么做到的 | 什么情况下它会失效 |
| **B 取舍轴** | 你做过决策，还是照抄方案 | 为什么用它不用另一个 | 换个条件你还这么选吗 |
| **C 证据轴** | 你的结论有没有依据 | 你怎么知道它有效 | 有没有反例 |

不是每个分点三条轴都成立。**至少选出两条**，覆盖「原理」与「取舍」的优先——这两条是技术面的主干。

---

## 轴 A：机制轴（原理 → 边界 → 失效）

| 层 | 问法 | 答案要求 |
| :--- | :--- | :--- |
| A1 | 它内部靠什么做到这件事 | 说出**机制**，不说名词。听众应能在脑子里画出数据流 |
| A2 | 那它的边界在哪 | 说出**约束条件**，最好带一个具体数值或阈值 |
| A3 | 什么情况下它会失效或给错结果 | 说出**失效模式**，并说明是显式失败还是静默错误 |

**为什么 A3 最有价值**：能主动说出失效模式的人，一定真正运行过这套东西。只会背原理的人到 A2 就空了。

**常见失误**：A1 用另一堆名词解释名词（"通过 CO-RE 实现了可移植性"——等于没说）。

---

## 轴 B：取舍轴（选型 → 代价 → 反转）

| 层 | 问法 | 答案要求 |
| :--- | :--- | :--- |
| B1 | 为什么用 A 不用 B | 给出**两个方案的真实差异**，且差异与场景相关 |
| B2 | 选 A 付出了什么代价 | 承认代价。答"没有代价"即判负 |
| B3 | 什么条件下你会改选 B | 说出**反转条件**，越具体越好 |

**为什么 B2 是关键**：技术面里"我的方案没有缺点"是最快的减分项。承认代价不会削弱你，反而证明你评估过。

**为什么 B3 是分水岭**：能说出反转条件，说明选择基于分析而不是跟风。这一层答得好，往往直接结束该轴的追问。

**常见失误**：B1 把 B 说成一无是处。真实的取舍里，被放弃的方案通常在某些维度更好。

---

## 轴 C：证据轴（观测 → 量化 → 反例）

| 层 | 问法 | 答案要求 |
| :--- | :--- | :--- |
| C1 | 你怎么知道它真的在工作 | 说出**可观测信号**，最好是现成的工具或指标 |
| C2 | 有量化数据吗 | **没有实测就明说没有**，然后给出该测什么、怎么测 |
| C3 | 有没有出现过反例 | 给一个**具体现象**，说明当时怎么判断的 |

**C2 的铁律**：不知道就说不知道，编数字是唯一不可修复的错误。一个准确说出的"我没测过，要测的话会看 X"，远胜一个模糊的"大概提升了百分之几十"。

**C3 的价值**：反例是可信度的来源。一个从没遇到问题的人，通常也没真正跑过。

---

## 怎么给一个分点选轴

1. 分点里出现**技术选型词**（"基于 X"、"引入 Y"）→ 必有轴 B。
2. 分点里出现**效果词**（"低开销"、"高性能"、"兼容"）→ 必有轴 C，且该词通常要在第 0 段判为「需限定」。
3. 分点里出现**机制词**（"校验"、"挂载"、"同步"）→ 必有轴 A。
4. 三条都占的分点，按 A→B→C 顺序输出（先原理后取舍最后证据，符合面试真实节奏）。

---

## 升级与分支规则（drill 用）

| 用户回答 | 动作 |
| :--- | :--- |
| 答在点上 | 同轴升一层 |
| 含糊、用术语糊弄 | 同层重问，要求给定义或具体例子 |
| 像背书、过于流畅 | 换变体：改条件、改规模、改环境 |
| 答错 | 不纠正，沿错误继续施压，让矛盾自己暴露 |
| 说不会 | 记下，换下一条轴 |

**换轴时机**：三层走完，或用户两次答不上。不要在同一层反复消耗。

---

## 通用变体清单（"像背书"时用）

把条件换掉，看答案还成不成立。这是识别「背的」还是「懂的」最快的手段。

| 变体维度 | 换法 |
| :--- | :--- |
| 规模 | 流量放大一百倍 / 连接数从一千到一百万 |
| 环境 | 换内核版本 / 换架构 / 目标端没有某个依赖 |
| 故障 | 其中一环挂掉 / 数据源给出错误值 |
| 时间 | 长期运行一个月 / 跨零点 / 时钟回拨 |
| 相反条件 | 如果反过来做会怎样 |
